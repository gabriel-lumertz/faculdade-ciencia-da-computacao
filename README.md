# Ciência da Computação

Repositório para acompanhar os estudos e materiais da graduação em Ciência da Computação.

## Conteúdo

- **`<N>-semestre/<Matéria>/`**: notas de cada disciplina.

## Organização das notas

```
<N>-semestre/
└── <Matéria>/
    ├── 00 - <Matéria>.md      ← índice da matéria (links para as unidades)
    ├── 01 - <Título>.md       ← uma nota por unidade (NN = número da unidade)
    ├── ...
    └── attachments/           ← imagens (WebP) usadas nas notas
```

- **Frontmatter** em cada nota: matéria, módulo, semestre, unidade, tipo, fonte, tags e aliases.
- **Fórmulas** em LaTeX (`$...$` e `$$...$$`).
- **Códigos** em blocos com a linguagem indicada. Capturas de tela de código foram transcritas.
- **Imagens** em `attachments/`, inseridas com `![[arquivo.webp]]`. Ícones e imagens decorativas foram removidos.
- **Partes removidas**: capas, créditos, orientações de estudo, sumários, material complementar, referências, atividades e gabaritos.
